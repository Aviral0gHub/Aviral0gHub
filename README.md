I study whether an AI system's reasoning and confidence deserve trust—and build evaluations that expose where they do not.

### Selected work

**[Last Translation Benchmark](https://last-translation-benchmark.vilda.net/)**  
I have co-authored LTBv1, a live multilingual translation benchmark developed by contributors from ETH Zürich, Johns Hopkins, MBZUAI, KIT, the University of Amsterdam, and many other institutions. My contribution focused on adversarial text inputs, with a high number of accepted submissions.  
[Paper](https://arxiv.org/abs/2609.04173) · [Dataset](https://huggingface.co/datasets/zouhar/last-translation-benchmark) · [Live leaderboard](https://last-translation-benchmark.vilda.net/leaderboard-results)

**[FactTrace](https://github.com/Aviral0gHub/facttrace)**  
Claim-level verification for LLM reasoning using evidence retrieval and natural-language inference.

**[CalibCheck](https://github.com/Aviral0gHub/calibcheck)**  
An evaluation of whether model confidence tracks actual correctness.
