## Selected work

<sup>01</sup> &nbsp; **[Last Translation Benchmark](https://last-translation-benchmark.vilda.net/)**

I have coauthored LTBv1, a live multilingual translation benchmark developed by contributors from ETH Zürich, Johns Hopkins, MBZUAI, KIT, the University of Amsterdam, and many other institutions. I designed adversarial text inputs and had a high number of accepted submissions.

[Paper](https://arxiv.org/abs/2609.04173) · [Dataset](https://huggingface.co/datasets/zouhar/last-translation-benchmark) · [Live leaderboard](https://last-translation-benchmark.vilda.net/leaderboard-results)

<sup>02</sup> &nbsp; **[FactTrace](https://github.com/Aviral0gHub/facttrace)**

Claim level verification for LLM reasoning using evidence retrieval and natural language inference.

<sup>03</sup> &nbsp; **[CalibCheck](https://github.com/Aviral0gHub/calibcheck)**

An evaluation of whether model confidence tracks actual correctness.
