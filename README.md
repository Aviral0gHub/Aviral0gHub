### Research & Project Architecture

#### <b>Robotics Research Center (RRC), IIIT Hyderabad</b>
* Developing end-to-end neural pipelines to isolate, index, and match target object instances across large-scale visual datasets.
* Implementing deep visual feature representations with high-throughput vector search (FAISS) for efficient image retrieval.
* Engineering automated embedding extraction and normalization pipelines to benchmark metric learning architectures.

#### <b>Featured Engineering Systems</b>
* **Learned Vegetation Index (LVI):** Deep regression pipeline mapping multispectral features to ground-truth LIDAR physical measurements ($R^2 = 0.592$).
* **Land Cover Visual Classifier:** Transfer learning classification pipeline using ResNet-18 backbones achieving 96.98% accuracy.
* **Last Translation Benchmark:** Contributed adversarial multimodal inputs to the upcoming publication organized by researchers from ETH Zurich, JHU, CUNI, UvA, and KIT.
